# HU04 - Consultar Cursos

## Descripción
Como profesor, quiero consultar los cursos asignados para poder gestionar estudiantes y calificaciones.

## Criterios de Aceptación
- Listar cursos del profesor en el semestre actual
- Ver cantidad de estudiantes matriculados
- Acceder a lista de estudiantes por curso
- Ver horario y aula de cada curso
