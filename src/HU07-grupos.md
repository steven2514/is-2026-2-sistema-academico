# HU07 - Crear Grupos

## Descripción
Como coordinador académico, quiero crear grupos académicos para asignar estudiantes a diferentes secciones de un curso.

## Criterios de Aceptación
- Crear un nuevo grupo para una asignatura
- Asignar profesor tutor del grupo
- Establecer capacidad máxima de estudiantes
- Asignar horario y aula
- Validar que no haya conflicto de horarios
